# Predicting Market Reactions to News (PMRTN)

Python package and CLI for studying how Spanish business news affects equity markets. The pipeline cleans and merges raw articles, extracts tickers, builds sentence embeddings, clusters news with KMeans, optionally parses shocks with LLAMA models via Groq, and downloads market data for downstream analysis.

## Repo Layout
- `src/PMRTN/` – library and CLI code (`pmrtn` entry point), including data loaders/processors, embeddings, clustering models, LLAMA parsing, visualization, and CLI commands.
- `tests/` – unit and integration tests for configuration, data utilities, and CLI commands.
- `htmlcov/` – sample coverage report output.
- `pyproject.toml` – project metadata, dependencies, and tooling configuration.

## Requirements
- Python 3.9–3.11 (per `requires-python`).
- A Groq API key (`GROQ_API_KEY`) for LLAMA-based parsing, if you run those steps.
- Access to the raw news parquet file and risk-free rate CSV referenced in your `config.yaml`.

## Installation (uv)
Install [uv](https://github.com/astral-sh/uv) if you don't have it (`pip install uv`), then:
```bash
uv venv
source .venv/bin/activate
uv pip install -e .
# For development:
uv pip install -e ".[dev]"
```

## Configuration
Commands look for `config.yaml` in the current directory, a `Master_Thesis-Replication_Package-main` subdirectory, or up to three parent directories. Override with `--config path/to/config.yaml`.

Example `config.yaml`:
```yaml
directories:
  raw_data: data/raw
  processed_data: data/processed
  output_descriptives: output/descriptives
  output_kmeans: output/kmeans
  output_llama: output/llama

files:
  raw_articles: articles.parquet

preprocessing:
  min_word_count: 20
```
Create the listed directories before running commands. Adjust paths to match where your data lives.

## CLI Quickstart
The package installs the `pmrtn` (and `news-analysis`) command.

- Check install and paths:
  - `pmrtn version`
  - `pmrtn info --config config.yaml`
- Process raw articles to CSV with tickers:
  - `pmrtn load-articles --config config.yaml --filter-agenda/--no-filter-agenda`
- Descriptive stats and plots:
  - `pmrtn describe-data --config config.yaml`
- Download market returns (needs risk-free CSV, e.g., ESTR):
  - `pmrtn download-returns --config config.yaml --rf-data data/raw/ESTR.csv --model KMeans`
- Generate sentence embeddings:
  - `pmrtn generate-embeddings --config config.yaml --model distiluse-base-multilingual-cased-v1`
- KMeans clustering on embeddings:
  - `pmrtn kmeans-clustering --config config.yaml --k-min 2 --k-max 10`
- LLAMA parsing of articles (slow, requires Groq):
  - `pmrtn llama-parse --config config.yaml --api-key $GROQ_API_KEY --model llama3-70b-8192`
- LLAMA clustering placeholder:
  - `pmrtn llama-clustering --config config.yaml`
- Run the full pipeline with optional skips:
  - `pmrtn run-all --config config.yaml --rf-data data/raw/ESTR.csv --model-type both --skip llama-parse`

## Data Expectations
- Raw articles: parquet with `publication_datetime`, `title`, `snippet`, `body`, company code fields; filtered to Spanish tickers (e.g., `TEF.MC`).
- Processed articles: CSV `articles_with_tickers.csv` containing `publ_datetime`, cleaned `articles`, and `tickers` lists.
- Embeddings: `articles_with_embeddings.csv` with an `embedding` column generated by sentence-transformers.
- Returns: `R_KMeans.csv` / `R_LLAMA.csv` with market and stock returns plus risk-free rates.
